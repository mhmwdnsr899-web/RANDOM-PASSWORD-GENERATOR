# RANDOM-PASSWORD-GENERATOR
It is application generate random passwords with ability to select from (letters,number..etc) and length of password.This app also can save password in JSON file with (secret.key) by fernet .It is completely run offline to save password with ability to share it but use share key also to be able to read JSON file.
There will be new versions for phones in next update.However just PC version or Web one to test.
